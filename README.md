# Interview Research Guide

A React-based interview guide application built with Vite and Tailwind CSS.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```

2. Run the app:
   ```
   npm run dev
   ```

3. Build for production:
   ```
   npm run build
   ```

## Deploy to Vercel

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy
